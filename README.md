\# Visual Node Calculator



Visual Node Calculator is a node-based arithmetic application developed in C++ using Dear ImGui and imnodes. It allows mathematical operations to be created visually by connecting nodes through an interactive editor.



\## Features



\* Visual node-based calculation system

\* Number input nodes

\* Addition, subtraction, multiplication, and division nodes

\* Result output nodes

\* Interactive pin and link connections

\* Movable nodes and canvas navigation

\* Zoom and pan support

\* Saving and loading node graphs

\* Real-time calculation updates

\* Custom editor interface



\## Technologies



\* C++

\* Dear ImGui

\* imnodes

\* DirectX 11

\* Win32 API

\* Visual Studio



\## Getting Started



1\. Clone or download the repository.

2\. Open `VisualNodeCalculator.slnx` in Visual Studio.

3\. Make sure the Desktop development with C++ workload is installed.

4\. Build the solution.

5\. Run the application from Visual Studio.



\## Project Purpose



This project was developed to explore immediate-mode graphical user interfaces and visual programming concepts. It demonstrates how arithmetic operations can be represented and evaluated through an interactive node graph.
